# Markio ✨

A modern Markdown editor and previewer built with Next.js.
Markio allows users to write, edit, and preview Markdown in real time with a clean and minimal interface.

> Recreated and enhanced using GitHub Copilot.

---

## 🚀 Features

* ⚡ Real-time Markdown preview
* 📝 Live editor with instant rendering
* 🎨 Clean and responsive UI
* 📱 Mobile-friendly design
* 🌙 Modern developer-focused interface
* 🔥 Built with Next.js
* 💡 Enhanced using GitHub Copilot

---

## 🛠️ Tech Stack

* **Next.js**
* **React**
* **Tailwind CSS**
* **React Markdown**
* **Remark GFM**

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/markio.git
```

Navigate to the project directory:

```bash
cd markio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
